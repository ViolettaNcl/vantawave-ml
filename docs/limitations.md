# Limitations

1. v0.3 still uses synthetic data for the bundled runnable demo.
2. No real-world detection claim is justified by demo metrics.
3. Wi‑Fi sensor ingestion is not implemented yet.
4. Incident severity and risk scoring are transparent engineering rules, not
   learned ground truth.
5. CatBoost, MLflow and Parquet support are optional extras.
6. Deep learning, SHAP, drift monitoring and RAG are roadmap items.
