# Support

For reproducible bugs and feature requests, use GitHub Issues.

Before opening an issue:

1. run `python -m pytest`;
2. run `python scripts/final_portfolio_check.py`;
3. include OS, Python version, VantaWave version, and reproduction steps;
4. remove credentials, private captures, tokens, and personal data from logs.

For security-sensitive reports, follow `SECURITY.md` rather than posting secrets publicly.
