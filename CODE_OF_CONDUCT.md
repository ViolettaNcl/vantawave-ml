# Code of Conduct

## Our standard

VantaWave ML welcomes technical discussion, bug reports, documentation work,
research feedback, and defensive-security contributions.

Participants are expected to be respectful, specific, evidence-oriented, and
professional. Harassment, personal attacks, doxxing, discriminatory behavior,
or attempts to use the project community to facilitate unauthorized access are
not acceptable.

## Security scope

Discussion of wireless-security concepts is welcome when it is framed around
owned or explicitly authorized systems, public research datasets, synthetic
simulation, defensive analysis, or reproducible research.

## Reporting

For project bugs, use GitHub Issues. For security-sensitive reports, follow
`SECURITY.md` and avoid publishing secrets, credentials, or private captures in
public issues.
