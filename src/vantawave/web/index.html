          What this module can and cannot do
          

            VantaWave can reveal a Wi-Fi key only when Windows already has that key saved locally.
            If this laptop has never connected to the SSID, there is no stored credential to reveal.
            The module can still scan the network, show legitimate recovery paths, audit a password
            you provide locally, and connect Windows using that supplied password.

          Authorized capture verification
          

            This page does not turn an SSID into a password. It analyzes a capture from an
            explicitly registered lab target, looks for WPA/WPA2 EAPOL evidence, and can ask
            Aircrack-ng to verify one password candidate you supply. Wordlist/brute-force APIs
            are intentionally not exposed.
